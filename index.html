Social Bill-Splitting Game

Split Roulette

Don't split the bill. Let fate split it.

Split Roulette is a free interactive bill-splitting tool for friends who want a playful alternative to dividing a restaurant, outing, or group expense evenly. Add the bill and participants, choose a distribution style, and let the tool calculate each person's share.

How Split Roulette works

  1. Enter the total bill and choose the currency.
  2. Add the people sharing the expense.
  3. Choose a distribution style, such as a fairer split or a more unpredictable split.
  4. Run the split and review each person's assigned amount.

The allocation is designed so the individual shares add up to the entered bill total, including the final rounding adjustment to the smallest currency unit. Split Roulette calculates suggested shares; it does not collect money, process payments, or transfer funds.

When can you use it?

Use the tool for a meal with friends, a group outing, shared entertainment, or another expense where everyone has agreed to use a randomized allocation. Discuss the result with the group before anyone pays. Random allocation is a game mechanic, not financial advice, and everyone should agree to the rules before starting.

Frequently asked questions

Does Split Roulette split the bill equally?

Not necessarily. The selected distribution style changes how the total is allocated among participants.

Will the shares add up to the exact bill?

The allocation logic is designed to make all participant shares add up to the entered total, accounting for currency rounding.

Does Split Roulette process payments?

No. It calculates and displays suggested amounts. Participants arrange payment separately.

Do I need an account?

The basic bill-splitting tool can be used without creating an account.
