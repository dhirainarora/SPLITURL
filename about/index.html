About Split Roulette

Split Roulette is a free web-based bill-splitting game for groups who want a playful alternative to dividing a shared expense evenly. Enter the bill total, add participants, choose a distribution style, and review each person's suggested share.

How it works

  1. Enter the total bill and currency.
  2. Add the participants.
  3. Choose a distribution mode.
  4. Run the split and review the allocation.

The allocation is designed so all shares add up to the entered bill total, including currency rounding. Split Roulette calculates suggested shares; it does not collect money or process payments.

When to use it

Use it for a meal, outing, or shared expense only when everyone involved agrees to the randomized allocation rules. Discuss the result before anyone pays. Random allocation is a game mechanic, not financial advice.

Frequently asked questions

Does it split bills equally?

Not necessarily. The selected distribution style changes how the total is allocated.

Does it process payments?

No. It calculates and displays suggested amounts; participants arrange payment separately.

Do I need an account?

The basic tool can be used without creating an account.
